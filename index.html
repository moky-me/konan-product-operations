Konan Product Operations

A private workplace assistant operated by its owner using Nous Hermes Agent on a virtual private server.

What the application does

Konan helps its owner and authorized collaborators find working context in designated Slack channels and a designated Google Drive folder. The Google Drive integration supports file listing, keyword search and supported document text retrieval. The current team interface does not expose Drive editing or deletion tools.

Google account access

The integration uses a separate Google account. Its owner shares the intended work folder with that account and authorizes Google Drive access. Google authorization covers the separate account; the application additionally restricts its Drive retrieval tools to the designated folder and descendants, including checking shortcut targets.

The integration is being configured. Access starts only after the owner completes Google consent and the server validates the connection. This application is for private use and has no public sign-up service.

Data and contact

OAuth credentials and application history are stored on the owner’s server. Retrieved document content may be sent through OpenRouter to the configured model provider to answer work requests. See the privacy policy for processing and deletion details.
